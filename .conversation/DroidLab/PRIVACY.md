# Privacy Policy for DroidLab

**Effective Date:** 2026-09-07

DroidLab is a privacy-first utility application. We believe your device data belongs exclusively to you.

## Data Collection

- **Zero Cloud Dependency:** DroidLab does not transmit any device, user, or usage data to external servers.
- **Local Analytics:** There are no analytics trackers, crash reporters, or telemetry agents embedded within the application.
- **Local Database:** Any historical data logged by the app (e.g., Battery History) is stored strictly in your device's local, sandboxed SQLite database using Android Room. This data is never exported without your explicit action.

## Permissions

DroidLab requests the following minimal permissions:
- **INTERNET & ACCESS_NETWORK_STATE & ACCESS_WIFI_STATE:** Required solely for the Network Diagnostics module to analyze the active local network configuration. No outbound connections are established automatically.

## Updates

If we decide to add optional opt-in telemetry in future versions (e.g., Firebase Crashlytics for stability), this Privacy Policy will be updated, and the feature will be disabled by default, requiring explicit user consent.
